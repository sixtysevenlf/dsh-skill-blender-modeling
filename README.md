# dsh-skill-blender-modeling

> **Blender 建模与装配流程 skill**（DSH / Claude 风格的 `skills/<name>/SKILL.md` 目录）
> 把「捏一个物体」和「**多个 agent 造一台机器**」都写成可执行流程 + 可跑的判据。

## 这是什么

一份**给 AI agent 读的建模作业指导书**：先按决策树选形，再走流水线，每一步都要有画面或数字证据。
与常见的「Blender 入门教程」不同，它按**实测反馈**写成 —— 每一条都是踩过之后才加进去的：

- **载体不匹配就换路子**：分面装甲板禁止上 SubSurf（会把棱边圆成肥皂）；编辑模式 `bpy.ops.mesh.*`
  在 `blender -b` 下 context 很脆 → 改 bmesh；
- **展示拼接 ≠ 真实连接**：面贴面必见缝，所以展示模型用**隐藏交叠**（不改可见轮廓、不捅穿薄壳），交叠量由
  **本项目 spec 明文**定、装配后按 spec 复核 —— **没有通用倍数或下限**；能不能承载由设计配合 / 标准 /
  承载工况 / 制造工艺 / 运动间隙规定，几何脚本不给强度结论；
- **判据必须有前提**：法线朝内会让所有"穿模 / 内含"判据整体反号（实测把贴合件误报成深入 150mm）；
- **指标必须有适用范围**：IoU 只是**单视轮廓**的必要条件（看不见深度/内部特征/面感）；单应只校正
  **取点那一个平面**（离平面 0.5m 实测误差 543mm）；跨深度误差不是固定 ±5% 而是 `Δz/(D+Δz)`；
- **验收不能靠肉眼**：形体要「同机位对照图 + 数值 bbox」两条证据。

## 安装

```bash
git clone https://github.com/sixtysevenlf/dsh-skill-blender-modeling.git
cd dsh-skill-blender-modeling

# 方式 A（推荐）：软链，改一处两边同步
ln -s "$PWD" ~/.dsh/skills/blender-modeling

# 方式 B：直接拷贝
cp -r . ~/.dsh/skills/blender-modeling
```

> ⚠ `SKILL.md` **必须保留 YAML frontmatter**（`name` / `description` / `license`）——
> 加载器靠它建目录；frontmatter 一掉，技能会直接从技能目录里消失（踩过）。

## 相对 v3 的改动（2026-09-26 · v4）：纠正被写死的错口径

按实测反馈纠正 v3 里**写错了的几条"通则"**。每条都先用本机 headless 量过再改（证据见下）：

| # | 原来写的（错） | 改成 | 实测证据 |
|---|---|---|---|
| 1 | 拼件**必须**互相插入 **5–15mm** | 嵌入深度按**接口类型与尺度**定（`1–2×` 接口特征尺寸）；5–15mm 只是"特征尺寸 5–30mm"那一档 —— ⚠ **本行已被 v6 取代**（固定倍数 / 下限与 5–30mm 推导全部撤回，见下节） | 3mm 薄板搭接 = 1.5mm **合格**；Ø6 轴 = 6mm；10mm **浮块**也满足 `overlap_bbox=true`，会被当成合格嵌入（`audit_measure` 回执） |
| 2 | 三视**必须共享同一个 px_per_mm**；比例互差 >3% ⇒ 判透视 | 正交**不推出**共享比例 —— 三张图可以各缩放却都是正交；**跨视互检要换算成毫米再比**，`s` 互差只决定"能不能合并" | 三个正交相机 `ortho_scale` 4/8/2：视差全 **0px**，`px_per_mm` = 0.48/0.24/0.96（差 **300%**） |
| 3 | 跨深度尺寸公差放宽到 **±5%** | 误差是 **`Δz/(D+Δz)`**，随深度线性放大；估不出 `D`/`Δz` 记 `unresolved` | D=8m：Δz=0.5m → **−5.88%**；1m → −11.1%；3m → **−27.3%**（与解析式逐行吻合） |
| 4 | 照片"必须先做透视校正（求单应），否则尺寸全错" | 单应**只校正取点那个平面**；平面参考完全正确，立体物只有该平面准 | 平面内 **0px**；离平面 0.05m → 52mm；0.2m → 211mm；0.5m → **543mm** |
| 5 | 用 IoU 判「像不像」 | IoU 是**单视轮廓**的**必要不充分**条件；看不见深度/内部特征/面感，且填满轮廓就能刷高 | 补进 §0.6.2 的盲区表 + SOP/验收清单同步 |
| 6 | 修改器顺序**背下来**一条固定链 | **不存在固定链** —— 按目标排，用求值回执核对 | 同一立方体：Bevel→SubSurf **864 面 bbox 0.9904** vs SubSurf→Bevel **96 面 bbox 0.8395**；Solidify↔Bevel 54 vs 6 面 |
| 7 | 内部面 → `Delete Loose` | `Delete Loose` **一个面都不删**；`select_interior_faces` 对 join 重叠壳也选 0 → 用 **Boolean UNION** 或射线法找埋面（§5.1） | Blender 打印 `Removed: … **0 faces**`（两种场景）；join 重叠对 `select_interior_faces` 选中 **0** |
| 8 | 配方 6b 是"恒原点"占位、节距用**等弧长**、`bbox ≈ n*pitch` | 改成**真正可运行**的闭合赛道形；区分**等弧长**与**销轴弦长**节距；修正 bbox 与对象数 | 弦长口径 `max|弦长−p|` = **3.3e-06mm** 且闭合；等弧长把弧上弦长压到 175.021mm（每节 −0.979mm，两弧累积 −11.75mm）；`bbox 最长边 = A+2R = 1.736m`（旧写法 1.056m，**错 680mm**）；对象数 = `2*(m+n_straight)` = 24（模板必须删） |

验收表（§0.5.5 / §6 / §6.1）与轻量清单（`references/验收清单.md`）已同步到新口径；
`references/modeling-overview.md`（上游英文收录）里同样的两处旧说法已就地标注纠正。

## 相对 v5 的改动（2026-09-26 · v6）：撤回"固定倍数 / 下限"通则

Lead 复查发现：v4/v5 只是把 `5–15mm` 换成"`1–2×` 接口特征尺寸"，**仍是同一种规范性固定倍数**，且与示例数字互相矛盾（"3mm 板最少 3mm" vs "1.5mm 合格"）。
本次**只做定点文本修订**（`SKILL.md` / `README.md`）：不重跑几何、不动插件、不动 `references/验收清单.md`。

| # | 改成 |
|---|---|
| 1 | **删除**所有规范性固定倍数 / 百分比 / 下限，以及"5–15mm = 特征尺寸 5–30mm 那一档"的推导：展示拼接可在**不改变可见轮廓、不捅穿薄壳**下选择**隐藏交叠**，交叠量由**本项目 spec 明文**规定并按 spec 复核 |
| 2 | **真实连接不由可视脚本裁定**：由设计配合、标准、承载工况、制造工艺与运动间隙规定；几何脚本只答"叠没叠 / 浮没浮 / 穿没穿"，不给结构强度结论 |
| 3 | 示例数字（Ø6→6mm、3mm 板→1.5mm）**只属于写明它的那份示例 spec，不是通则** |
| 4 | `axis_overlap_mm` 的 AABB 读法补前提：**仅接口法线与世界轴一致且轴对齐盒适用时才作粗筛**；**旋转 / 斜置接口沿真实接口的局部坐标量测真实表面**，不能挑一根世界轴当深度 |

历史复盘（§9–§12 与上面的 v4 表）已就地标注**被 v6 取代**；正文改动清单见 `SKILL.md` §13。
